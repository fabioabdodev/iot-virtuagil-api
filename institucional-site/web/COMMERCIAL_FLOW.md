# Fluxo comercial do site institucional

## Atendente IA

1. O visitante conhece o produto no site.
2. O CTA leva para a Jade no WhatsApp.
3. A Jade apresenta o Atendente IA, responde duvidas e qualifica o interesse.
4. Quando necessario, a conversa e transferida para atendimento humano.
5. A contratacao e formalizada conforme plano/volume aprovado.
6. O pagamento pode ser realizado pelo Mercado Pago quando o link oficial estiver configurado em `NEXT_PUBLIC_MERCADO_PAGO_PAYMENT_URL`.

## Automacao de Processos e IoT

Essas frentes seguem por avaliacao de escopo e proposta. A Jade, nesta versao, permanece focada na venda e demonstracao do Atendente IA.

## Separacao de sistemas

- `virtuagil.com.br`: site institucional e comercial.
- `monitor.virtuagil.com.br`: plataforma IoT. Nao alterar a partir deste projeto comercial.
- `api.virtuagil.com.br`: API da plataforma IoT. Nao alterar a partir deste projeto comercial.
